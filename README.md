# Firma Shop — новый сайт

Что это: заготовка нового интернет-магазина взамен firmashop.prom.ua.
Сайт уже собирается и открывается локально, но работает пока на тестовых
данных (без настоящей базы данных, оплаты и доставки — это следующий этап).

## Что внутри

- `src/app/` — все страницы сайта (главная, каталог, товар, корзина, кабинет, админка)
- `prisma/schema.prisma` — структура базы данных
- `src/services/` — заготовки интеграций с Новой поштой и LiqPay (без ключей пока не работают по-настоящему)
- `.env.example` — список всех "ключей доступа", которые понадобятся позже

## Как посмотреть у себя на компьютере

Нужен установленный Node.js (версия 20 или новее).

```
npm install
npm run dev
```

Дальше открыть в браузере: http://localhost:3000

## Что НЕ готово (следующие шаги)

- Реальная база данных (сейчас везде тестовые/примерные товары)
- Настоящая оплата и доставка (нужны аккаунты в LiqPay и Новой пошті)
- Настоящий хостинг (сейчас сайт работает только на твоём компьютере)
